This example demonstrates using `maplibre-gl-three` with NPM and webpack.

You can run it with:

```
npm install
npm start
```

### library developpment

If you are making changes to `maplibre-gl-three`, you can point this example to use your local copy as a dependency with: 

```
npm run local_dependency
npm start
```

To reset this:

```
npm run registry_dependency
npm start
```
