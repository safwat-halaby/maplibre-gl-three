The original source of this 3D Tiles model is https://pelican-public.s3.amazonaws.com/3dtiles/agi-hq/tileset.json

This URL is listed under the "Open Data" section in the Cesium repository: https://github.com/CesiumGS/3d-tiles/blob/main/RESOURCES.md#open-data

I could not find the explicit license of this dataset,
but this has been used in the official MapLibre 3D Tiles examples prior to the creation of this library.
